# goit-pycore-hw-05

Домашня робота: замикання, рекурсія, генератори, функції як аргументи
та декоратори. Виконано всі чотири завдання, зокрема додатковий аналізатор
лог-файлів.

## Запуск

Потрібен Python 3.10 або новіший. Усі завдання використовують стандартну
бібліотеку Python, тому встановлювати сторонні пакети не потрібно.
Відкрийте термінал у папці проєкту та виконайте:

```bash
python hw01.py
python hw02.py
python hw03.py data/example.log
python hw03.py data/example.log error
python hw04.py
```

У Linux/macOS за потреби замініть `python` на `python3`.

## Завдання 1 — Фібоначчі з кешуванням

Файл: [hw01.py](hw01.py).

`caching_fibonacci()` створює словник `cache` та повертає вкладену функцію
`fibonacci(n)`. Значення обчислюються рекурсивно, зберігаються в кеші й
повторно використовуються під час наступних викликів того самого замикання.
Кожен виклик `caching_fibonacci()` створює незалежний кеш.

```python
from hw01 import caching_fibonacci

fib = caching_fibonacci()
print(fib(10))  # 55
print(fib(15))  # 610
```

Для `n <= 0` функція повертає `0`, для `n == 1` — `1`, відповідно до
псевдокоду з умови. Аргумент має бути цілим числом. Оскільки використано
рекурсію, максимально доступне `n` залежить від обмеження глибини рекурсії
Python; налаштування інтерпретатора код не змінює.

## Завдання 2 — генератор чисел і сума доходів

Файл: [hw02.py](hw02.py).

`generator_numbers(text)` знаходить числа регулярним виразом і повертає їх
по одному через `yield`. Числа мають бути відокремлені пробільними символами
або розташовані на початку чи в кінці тексту. Числа всередині слів або
безпосередньо поряд із розділовими знаками не враховуються.

Підтримуються цілі та дробові числа з крапкою, знак `+`/`-` і науковий
запис, наприклад `1e3`. `sum_profit(text, func)` викликає передану
функцію-генератор і підсумовує її значення.

```python
from hw02 import generator_numbers, sum_profit

text = (
    "Загальний дохід працівника складається з декількох частин: "
    "1000.01 як основний дохід, доповнений додатковими надходженнями "
    "27.45 і 324.00 доларів."
)
print(sum_profit(text, generator_numbers))  # 1351.46
```

Якщо чисел немає, сума дорівнює `0.0`.

## Завдання 3 — аналізатор логів (додаткове)

Файл: [hw03.py](hw03.py). Приклад даних: [data/example.log](data/example.log).

Реалізовано всі функції з умови: `parse_log_line`, `load_logs`,
`filter_logs_by_level`, `count_logs_by_level`, `display_log_counts`.
Для фільтрації використано списковий вираз.

```bash
python hw03.py data/example.log error
```

Другий аргумент необов'язковий і не залежить від регістру. Підтримуються

## Завдання 4 — бот з декоратором input_error

Файл: [hw04.py](hw04.py).

Бот продовжує домашню роботу №4. Кожен обробник команд має декоратор
`@input_error`, який обробляє `KeyError`, `ValueError` та `IndexError`,
повертаючи повідомлення замість аварійного завершення програми.
`functools.wraps` зберігає ім'я й метадані обгорнутої функції.

```bash
python hw04.py
```

Вводьте команди по одній:

```text
hello
add
add Bob
add Bob 0501234356
phone BOB
change bob 0671234567
phone missing
phone
all
exit
```

| Команда | Результат |
| --- | --- |
| `hello` | `How can I help you?` |
| `add name phone` | Додає контакт: `Contact added.` |
| `change name phone` | Змінює наявний контакт: `Contact updated.` |
| `phone name` | Показує номер. |
| `all` | Показує всі контакти. |
| `close` або `exit` | `Good bye!` та завершення роботи. |

Приклади обробки помилок:

- `add`, `add Bob`, `change Bob` → `Give me name and phone please.`
- `phone` → `Enter user name.`
- `phone missing`, `change missing 123` → `Contact not found.`
- Невідома команда або порожнє введення → `Invalid command.`
- Зайві аргументи команд → повідомлення про правильний формат; бот
  продовжує працювати.

Команди й імена не залежать від регістру, ім'я має бути одним словом.
Імена зберігаються малими літерами. Номери зберігаються рядками, тому
початковий нуль не губиться. Повторна команда `add` для того самого імені
оновлює номер. Контакти зберігаються лише протягом поточного запуску.
Усі `input()` і `print()` бота розташовані тільки у `main()`.
